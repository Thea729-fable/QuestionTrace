# 唯一演示案例

本案例使用虚构候选人“林思远”应聘阿里巴巴 AI Agent 产品经理（2027 届应届生），不包含参赛者真实简历。岗位 JD 见：

- `inputs/alibaba-ai-agent-product-manager-jd-page-1.png`
- `inputs/alibaba-ai-agent-product-manager-jd-page-2.png`

## 演示路径

1. 使用百炼 CLI `qwen3.5-omni-plus` 解析 JD 与简历，提取岗位职责、企业员工场景、技能要求和候选人触发点；
2. 生成 AI Agent 产品经理、企业效率产品、智能助手、自动化工作流、知识管理等受控检索词；
3. 通过 Museon 检索和深读真实社媒面经；本仓库演示为已完成审计的历史证据回放；
4. 实时新运行时，将每张可访问题图交给 `qwen3.5-omni-plus` 提取可见问题并记录调用状态；
5. 将面经主题与 JD、简历经历进行三方匹配并执行证据审计；
6. 生成个性化押题题库 Markdown。

为方便评委直接查看，本案例采用截至 2026-08-07 的 AI 与 Agent 产品经理历史证据回放。旧版 147 张题图的审计记录来自当时的 Museon 视觉分析流程，本仓库保留这一事实，不把它改写成新的百炼调用。当前 Skill 的实时新运行必须先完成百炼运行时校验，并由 `qwen3.5-omni-plus` 解析本次 JD、简历和全部可访问题图；未成功调用时停止，不回退为宿主模型看图。

回放只用于展示输出结构和旧版证据规模，不等同于针对阿里巴巴 AI Agent 产品经理 JD 的当日实时检索，也不能替代新版端到端测试。新版测试完成后，应保留新的百炼运行审计信息，但不提交任何凭证、原帖全文、创作者标识、临时媒体链接或原始题图。
