# 唯一演示案例

本案例使用虚构候选人“林思远”应聘阿里巴巴 AI Agent 产品经理（2027 届应届生），不包含参赛者真实简历。岗位 JD 见：

- `inputs/alibaba-ai-agent-product-manager-jd-page-1.png`
- `inputs/alibaba-ai-agent-product-manager-jd-page-2.png`

## 演示路径

1. 从 JD 图片提取阿里巴巴 AI Agent 产品经理职责、企业员工场景和技能要求；
2. 生成 AI Agent 产品经理、企业效率产品、智能助手、自动化工作流、知识管理等受控检索词；
3. 调用已完成深度审计的真实 AI 与 Agent 产品经理历史证据库（演示证据回放）；
4. 展示 42 份面经和 147 张题图的完整读取结果；
5. 将面经主题与 JD、简历经历进行三方匹配；
6. 生成个性化押题题库 Markdown。

为方便评委直接查看，本案例采用截至 2026-08-07 的 AI 与 Agent 产品经理历史证据回放。该回放用于展示深度阅读和题图审计能力，不等同于针对阿里巴巴 AI Agent 产品经理 JD 的当日实时检索。运行日期和证据采集日期必须在输出中明确；真实用户运行时仍按其上传的当前 JD 实时检索并建立岗位专属证据库。
